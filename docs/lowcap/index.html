A different game with its own rules. There is no size premium; small caps are a hunting ground, where mispricing is largest because nobody is looking — and where junk is the default state. So this desk asks its own questions, in its own order: Survive first — the Forge probes dilution, cash runway, distress and delisting jeopardy, and any severe finding removes the name before any upside analysis (shown below, with the finding named). Then four lenses, side by side and never merged: Graham deep value, GARP (Lynch/Slater), downside-first value (Pabrai/Burry) and the quality compounder (Cassel/Fisher). Each lens speaks, stays silent, or refuses when its inputs are unmeasured. There is no combined low-cap score anywhere on this page — a name on two lists is simply, visibly, on two lists.
